Состояние

Перед сбросом поставь расписание на паузу и дождись завершения сбора. Только сохранённые оригиналы (обычно до 14 дней). История предложений и антиповтор сохраняются. Затем нажми «Собрать сейчас» вручную; сам сброс не запускает ИИ.

Удаление тестовых данных

Удаляет все локальные посты, предложения (включая опубликованные и отклонённые), журнал и отчёты расходов. Сбрасывает историю и антиповтор. Настройки, каналы и входы сохраняются; сообщения Telegram и файлы сервера не удаляются.

Стоимость сборов · постфактум

Только LLM внутри сбора, включая попытки и повторы. Не счёт к оплате; без затрат Telegram, сервера и переписываний вне сбора. Последние 20 циклов.

Статистика

Настройка — шаг за шагом

Пройди шаги по порядку. Готовые отмечаются сами.

    Общие подключения: один читатель и бот, общий провайдер и API-ключ ИИ для всех пространств.

    1. Telegram API

    Ключи приложения с my.telegram.org → API development tools. Нужны и читателю, и боту.

    2. Аккаунт-читатель

    Через этот аккаунт бот читает каналы. Лучше отдельный, не основной.

    Подключён:

    Telegram на телефоне → Настройки → Устройства → Подключить устройство. Сканируй QR только для входа в эту панель.

    Не пересылай код никому и не отправляй его в чаты — Telegram сразу аннулирует код, если увидит его в сообщении. Вводи только здесь.

    На аккаунте включена двухэтапная аутентификация. Введи облачный пароль Telegram.

    3. Бот

    Создай бота у @BotFather командой /newbot и вставь токен. Через бота приходят новости на модерацию и идёт публикация.

    Привяжи свой Telegram

    Открой бота по кнопке и нажми «Запустить» — он запомнит тебя как администратора.

    Открыть бота и привязать

    Если кнопка не сработала — отправь боту:

    4. Канал для публикаций

    Добавь бота в администраторы канала с правом «Публикация сообщений». Для приватного канала проще переслать боту пост из него.

    5. Нейросеть

    Любой OpenAI-совместимый API. Подписка ChatGPT не подходит — нужен API-ключ.

    Необязательные тарифы для текущей модели. Укажи подтверждённые цены провайдера, без придумывания. Оценка по обычным входным/выходным токенам; кэш, скидки и доплаты не учитываются. Если ответ содержит стоимость OpenRouter, она приоритетна.

    Контент-план этого пространства

    Автоматическая подготовка и публикация в выбранные дату и время — только при включённом плане. Пауза новостей не влияет на план. Текущая работа может завершиться после паузы; новые задания не стартуют.

    Модель, тарифы и длина поста

    Необязательные подтверждённые тарифы. Пусто — неизвестная стоимость, не ноль. Смена провайдера или модели сбрасывает прежние тарифы; новостные тарифы не меняются.

    Новая тема

    Канал сохраняется при добавлении темы из «Публикация». Изменение канала пространства не перенаправляет ранее созданные темы. Сохранение не запускает ИИ; включённый план запустит подготовку и публикацию в назначенное время.

    Вставить несколько тем · по одной на день

    До 30 тем, по одной строке. Последовательные даты с указанным временем; проверяются все темы до добавления. Без автоматического платного вызова при сохранении.

    Каналы-источники

    @username, ссылки t.me/… или id вида -100… — можно сразу списком. Приватные: сначала подпиши на них аккаунт-читатель.

    ИИ-прогноз

    Условный аналитический сценарий для новых и переписанных обычных новостей этого пространства. Не факт и не обещание точных дат. Уже сохранённые посты не меняются.

    Характер модели

    Каким голосом пишутся новости.

    Явный вызов ИИ с моделью этого пространства. Расход записывается отдельно как character_prompt. Результат можно редактировать; применяется только после «Сохранить».
